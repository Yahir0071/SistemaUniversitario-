# 🏛️ Sistema Universitario

> Proyecto desarrollado para la entrega de la **Tarea de la Semana 11**.

---

## 📝 Descripción del Proyecto
Este sistema es una aplicación diseñada para gestionar procesos universitarios académicos de manera eficiente. El objetivo principal es resolver la problemática planteada en la guía de la semana 11 mediante código limpio y estructurado.

## 🚀 Características Principales
*   **Gestión de Alumnos:** Registro, edición y consulta de datos.
*   **Control de Notas:** Cálculo automatizado de promedios ponderados.
*   **Interfaz Intuitiva:** Navegación amigable a través de la consola/menú.

## 🛠️ Tecnologías Utilizadas
*   **Lenguaje:** Java / algo de CSS
*   **Herramientas:** Git, GitHub
*   **Entorno de Desarrollo (IDE):** VS Code / IntelliJ
